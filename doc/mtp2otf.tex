\section{Overview}
mtp2otf converts MathTime\texttrademark{} Professional 2 (MTPro2) Type~1
fonts and TeX metrics to OpenType MATH. It preserves the source designs,
including optical script sizes, and supplies the layout
data used by Unicode math engines. Upright Latin letters and additional
text characters come from a separate Roman font pair.

The converter produces OTF for LuaLaTeX and TTF for Microsoft Word.
Full and Lite use separate family names and can be installed together.
The selected edition requires the corresponding MTPro2 source files.

No additional mtp2otf package is needed to use the generated fonts.
Unicode characters and OpenType features provide access to the designs.
The original \file{mtpro2} package's custom commands are not included.
See \file{mtp2otf-guide.pdf} for illustrated font usage and character variants.

\section{Building the fonts}\label{sec:build}
\subsection{Requirements}
The build requires a POSIX shell, Python~3.10 or later with fontTools,
FontForge with Python~3.10 or later support, and \file{tftopl} from
TeX Live. These commands must be on PATH.

Create \file{mtpro2/} and \file{donors/} beside \file{build.sh}.
Supply the font files separately:
\begin{itemize}
\item \file{mtpro2/}: MTPro2 PFB/TFM files and \file{mtpro2.sty}.
Full also requires \file{umt2ms.fd}, \file{umt2mf.fd},
\file{umt2bb.fd}, and \file{umt2hrb.fd}.
\item \file{donors/}: \file{NimbusRoman-Regular.otf} and
\file{NimbusRoman-Bold.otf} from Artifex urw-base35.
\end{itemize}
Place the files directly in these directories. The build reports missing
inputs for the selected edition.

Another Roman pair can be selected with the options below. The faces must
be static CFF OTF or TrueType TTF, upright and proportional, from the same
family, and have the required Latin and digit coverage and Regular/Bold
weights.

\subsection{Build options}
The default build uses Full and minimal donor coverage:
\begin{samepage}
\begin{verbatim}
./build.sh
\end{verbatim}
\end{samepage}
Select Lite, extended donor coverage, or a different Roman pair as needed:
\begin{samepage}
\begin{verbatim}
./build.sh --edition=lite
./build.sh --donor-coverage=extended
./build.sh --roman-regular=/path/to/Regular.otf \
           --roman-bold=/path/to/Bold.otf
./build.sh --help
\end{verbatim}
\end{samepage}
The edition and donor options can be combined. Relative donor paths are
resolved from the current directory; project paths are relative to
\file{build.sh}.

Minimal coverage uses a fixed selection of Roman characters. Extended
coverage adds eligible characters available in the Regular donor, without
replacing MTPro2's mathematical glyphs. It does not add Full-only features
to Lite. Appendix~\ref{sec:donors} lists the selection rules.

\subsection{Output}
The generated fonts are placed in \file{out/}:
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
Edition & OTF & TTF \\
\midrule
Full & \file{MTPro2Math.otf} & \file{MTPro2Math.ttf} \\
Lite & \file{MTPro2MathLite.otf} & \file{MTPro2MathLite.ttf} \\
\bottomrule
\end{tabular}
\end{center}
Install the generated fonts manually. Errors are reported on stderr;
generation diagnostics are recorded in \file{build/<edition>/build.log}.
Check the command's exit status: a failed build may leave previous output
files in place. Do not run concurrent builds of the same edition.

\section{Using the fonts}\label{sec:use}
\subsection{Microsoft Word}
Install the TTF and select \file{MTPro2 Math} or
\file{MTPro2 Math Lite} as the equation font. For the equation text,
enable \emph{Kerning for fonts} at 1~pt and above in the Font dialog.
In Microsoft 365 Word for Windows, as tested on 22 October 2026,
italic correction is not applied to ordinary character spacing, so spacing
may differ slightly from the original Type~1 output.

Use Word's equation editor for mathematical alphabets, accents, delimiters
and operators. It does not expose the same OpenType feature controls as
LuaLaTeX. The explicit feature examples in \file{mtp2otf-guide.pdf} are for LuaLaTeX.

\subsection{LuaLaTeX}
Load the OTF with \file{unicode-math}:
\begin{samepage}
\begin{verbatim}
\usepackage{unicode-math}
\setmathfont{MTPro2Math.otf}
\end{verbatim}
\end{samepage}
For Lite, use \file{MTPro2MathLite.otf}. If the font is not installed,
specify its directory with the \file{Path} option.

Use \file{unicode-math} commands for alphabets and symbols, and the usual
math structures for scripts, fractions, accents and delimiters.
See \file{mtp2otf-guide.pdf} for input examples and visual comparisons;
Appendix~\ref{sec:alphabets} lists the exact feature inputs.

Luaotfload 3.29 can omit pair kerning between script-size variants.

The font can also be used with \file{lua-unicode-math}.

\section{Metrics and MATH constants}\label{sec:scalars}
\subsection{Glyph metrics}
The output uses 1000 units per em. For an untransformed MTPro2 glyph,
the TFM width supplies its advance and the TFM italic correction supplies
its MATH italic correction.
Ordinary GPOS pair adjustments store the TFM pair kern without an added italic-correction term.
Skewchar pairs are excluded from
ordinary kerning; scripts, primes and accents have separate positioning
data. Top-accent attachment for source math alphabets is based on
\[
  \frac{\operatorname{CHARWD}+\operatorname{CHARIC}}{2}
  + \operatorname{skewkern}.
\]
For untransformed source alphabets, the calculation uses the exact TFM
fixed-point values and is rounded once to output units. Combining accents
and synthesized forms use the corresponding coordinate transformations
and geometric attachment positions. Text, script and scriptscript designs use the source
optical sizes.

\subsection{Constants}
The following assignments define the 56 MATH constants and the common
connector overlap in both editions. They combine source metrics, package
script ratios and conversion policies.

The expressions follow \file{tools/native_math.py} in evaluation order.
\texttt{round} uses nearest-integer rounding, ties to even; \texttt{//} is
floor division and \texttt{Fraction(a,b)} is exact rational arithmetic.
Intermediate rounding is part of each assignment.

\texttt{upm} is the output units per em. \texttt{s(i)} is
\texttt{round(sy[i] * upm)}, with \texttt{sy} from \file{mt2syt.tfm};
\texttt{e(i)} uses \file{mt2exa.tfm}. \texttt{theta = e(8)} and
\texttt{xh = s(5)}. \texttt{script\_sy} comes from \file{mt2sys.tfm}.
The script ratios are the \file{mtpro2.sty} defaults;
\texttt{\_pct(r)} is \texttt{round(r.numerator * 100 / r.denominator)}.

\texttt{display\_operator\_min\_height} is computed from the 30 mapped
text/display operator pairs in \file{mt2exa.tfm}. Round each height-plus-depth
to output units, then take
\texttt{(max(text sizes) + min(display sizes)) // 2}.
The source values give \texttt{(1103 + 1203) // 2 = 1153}.
The delimited-subformula threshold uses the same value. This is a conversion
policy; TFM box dimensions and OpenType glyph bounds need not select the
same design in every series.

\texttt{cap\_height} is the TFM height of \texttt{A} (slot \texttt{0x41})
in \file{mt2mit.tfm}, before conversion to output units.
Where MATH provides only one shift for display and inline superscripts,
the display value is used. Fields with separate display values retain both.
MathLeading uses the median of the em-normalized Latin Modern Math,
STIX Two Math and Cambria Math reference values. These fonts are not
build dependencies.

Source labels: MT-TFM, TFM parameters; MT-STY, package declarations;
MT-PFB, outlines; OT-SUG, OpenType suggested formulas; TeX, the script-space
convention; OT-MIG and MT-MIG, conversion policies. Combined labels indicate
that both source data and an assignment policy contribute.

Values are in font units except the script and radical-degree percentages.
The initial connector overlap is reduced to the nonnegative integer minimum
joining run when required by outline geometry. Both connector ends of
repeatable parts participate; fixed outside ends do not.

\subsection{Extended coverage and eligibility}
Extended retains actually encoded Regular characters in U+0020--036F,
U+1E00--1EFF, U+2000--218F, U+2500--266F, U+301A--301B and U+FB00--FB06,
subject to MTPro2 ownership and edition restrictions. The following
ranges are excluded:
U+0370--03FF, U+0400--052F, U+2100--214F, U+2190--21FF,
U+2200--22FF, U+2300--23FF, U+25A0--25FF, U+27C0--27EF,
U+2980--2AFF and U+1D400--1D7FF. Exceptions U+2105, U+2116,
U+211E, U+2120, U+2121, U+2122 and U+212E remain subject to the same ownership and edition restrictions.
Primes U+2032--2037/U+2057, PUA U+E000--F8FF, U+FEFF/U+FFFD and
existing output names are reserved. Imported glyphs must have usable outlines and metrics.
The Bold donor requirements are unchanged by extended coverage.

The additional coverage depends on the donor pair.
